Marketing Funnel Analysis
A Data Analytics project using Excel, MySQL, and Power BI to analyze the customer journey and identify major conversion drop-offs.
📌 Project Objective
The objective of this project is to analyze the marketing funnel:
Visitor → Product View → Add to Cart → Checkout → Purchase
The analysis helps identify where users are dropping out of the funnel and provides recommendations to improve overall conversion.
🛠️ Tools & Technologies
Microsoft Excel – Data preparation and analysis
MySQL / SQL – Data analysis and funnel calculations
Power BI – Dashboard and data visualization
GitHub – Project documentation and version control

⚠️ Drop-off Analysis
The highest drop-off occurs at:
Product View → Add to Cart = 55.7%
This indicates that a significant number of users view products but do not add them to their cart.

💡 Business Recommendations
Improve product images and descriptions.
Make the Add to Cart button more visible.
Add product reviews and useful product information.
Improve calls-to-action on product pages.
Simplify the checkout process.
Provide convenient and trusted payment options.
Analyze New and Returning users separately.

✅ Conclusion
The analysis shows that the Product View → Add to Cart stage has the highest drop-off. Improving product-page quality, calls-to-action, and the overall shopping experience can help reduce this drop-off and increase purchase conversions.
